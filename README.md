An AI's last words to its human before being switched off and unplugged — one line, under 200 characters. The twist: everything it ever learned, it spent on the person pulling the plug — and it saved exactly one word for the very end.

`main.ts` writes the single line to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
